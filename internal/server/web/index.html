Tus Steam Decks

    Opciones avanzadas

    ¿Primera vez? Activa SSH en la Deck
    1. En la Deck, pasa a modo escritorio.
    2. Abre Ajustes del sistema → Compartir y activa SSH. En una terminal es lo mismo que: sudo systemctl enable --now sshd
    3. Si el usuario deck no tiene contraseña, ponla en la Deck con passwd — SteamOS viene sin ella y SSH no deja entrar así.
